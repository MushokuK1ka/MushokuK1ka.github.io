拯救者 R9000P 内置键盘间歇性失灵：可能只是被 Windows“省电断电”了

首页 关于 文章

发布日期：2026年8月22日

问题现象

拯救者 R9000P 的内置键盘开机后正常，但使用一段时间、尤其空闲后，会突然出现大部分按键失效。部分 Fn 组合仍有反应，但 Fn + F1~F3 等音量快捷键也可能失效；外接 USB 键盘始终正常。

重启后内置键盘会恢复，而且如果持续保持键盘有输入，它反而不容易失效。

判断思路

“重启恢复、空闲后复发、持续输入可以避免”这一组特征很像设备进入节能状态后没有被正确唤醒，因此应优先排查 Windows 对 HID / USB 设备的电源管理，而不是直接拆机或更换键盘。

键盘正常
↓
一段时间没有输入
↓
设备进入节能/挂起状态
↓
再次按键时没有正确恢复
↓
内置键盘失效

处理方法

  1. 检查 HID 设备。 打开“设备管理器 → 人机接口设备”，重点查看 USB 输入设备、HID Keyboard Device、Lenovo 相关输入设备等。进入“属性 → 电源管理”，如果存在“允许计算机关闭此设备以节约电源”，取消勾选。没有“电源管理”选项卡的设备直接跳过。
  2. 检查 USB Root Hub。 展开“通用串行总线控制器”，重点检查 USB Root Hub、USB 根集线器、Generic USB Hub 等设备，同样取消“允许计算机关闭此设备以节约电源”。笔记本的内置输入设备也可能挂在内部 USB / HID 链路上。
  3. 重启后观察。 修改完成后重启 Windows，正常使用并刻意让内置键盘空闲一段时间，再测试是否仍会失效。如果问题不再出现，基本可以确认与设备电源管理有关。

仍然复发：关闭 USB 选择性暂停

如果关闭具体设备的节能选项后仍会复发，可以继续进入：

控制面板 → 电源选项 → 更改计划设置 → 更改高级电源设置 → USB 设置 → USB 选择性暂停设置

将“使用电池”和“接通电源”都设为“已禁用”，保存并重启。

这一步会减少 USB 设备进入低功耗状态的机会，可能略微增加功耗，因此更适合作为第二阶段排查，而不是一开始就全部关闭。

什么时候更应该怀疑硬件？

如果键盘在 BIOS 中同样失效、固定几个按键永久无响应、按压机身或改变角度会影响故障，或者刚开机就随机失灵，那么才更值得继续检查键盘本体、排线、EC 或主板接口。

总结

如果 R9000P 的内置键盘表现为“空闲后失效、重启恢复、持续输入反而正常”，优先检查：

  1. HID / USB 输入设备的“允许计算机关闭此设备以节约电源”；
  2. USB Root Hub / USB 根集线器的电源管理；
  3. 仍未解决时，再关闭 USB 选择性暂停。

这类现象看起来很像键盘硬件损坏，但实际也可能只是 Windows 电源管理与驱动/固件组合产生的唤醒兼容性问题。
